# MCP tool reference

Generated by `node scripts/gen-tools-doc.mjs`. The skills call these tools; you rarely need them directly.

## setup_check

Check prerequisites for the Research Copilot: FFmpeg, local transcription (whisper.cpp), research folder location, git safety, and configuration. Run before the first study.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `folder` | string |  | Research folder path; defaults to ./research found from the working directory |

## setup_init

Create and configure the research folder. Recordings stay in this folder on a company-managed laptop or a company drive folder. Asks the user to confirm the device is company-managed with disk encryption.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `path` | string | yes | Where to create the research folder, e.g. ./research or a OneDrive/Google Drive folder |
| `location` | string: laptop, drive | yes |  |
| `confirm_managed_device` | boolean | yes | The user confirmed this is a company-managed device with full-disk encryption |
| `product_name` | string |  |  |
| `relay_url` | string |  | Short relay URL for unmoderated tests (relay/template.yaml output) |
| `runner_base_url` | string |  | Where participant pages are hosted, e.g. https://research.example.com/ |
| `whisper_model` | string |  | Path to a whisper.cpp model file, e.g. ~/models/ggml-large-v3-turbo.bin |
| `user_name` | string | yes | Name of the researcher, recorded in logs and decisions |
| `model_account` | string: claude-enterprise, claude-team, api-bedrock, api-vertex, api-anthropic, cursor |  | The organisation's approved model account in use: Claude Enterprise or Team plan, Claude API via Bedrock, Vertex or Anthropic, or Cursor with an approved Claude model |

## results_import

Fallback import from the current testing tool: its results CSV (one row per participant) and, optionally, one video file per participant. Rows become sessions P1, P2… The tool's participant ids stay in a private mapping file; cell values are never returned. Only use for participants who consented in that tool to this research use.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `folder` | string |  | Research folder path; defaults to ./research found from the working directory |
| `slug` | string | yes | Study folder name, e.g. savings-onboarding-v1 |
| `csv_path` | string | yes |  |
| `participant_column` | string | yes | Column with the tool's participant or session id |
| `tasks` | array | yes |  |
| `sus_columns` | array |  | The 10 SUS item columns in order, answers 1 to 5 |
| `video_column` | string |  | Column with each participant's video file name |
| `video_dir` | string |  |  |
| `consent_confirmed` | boolean | yes | The researcher confirms these participants consented in the testing tool to this use |
| `consent_version` | string | yes | Which consent text they agreed to, e.g. the tool's standard terms plus our study notice v1 |

## observations_submit

Submit the observations (one idea each, ≤ 40 words) for one session. Every quote is checked word for word against participant utterances; every event and frame id must exist. Rejected items are returned with reasons and are not saved. Fix and resubmit only by re-reading the evidence; never invent.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `folder` | string |  | Research folder path; defaults to ./research found from the working directory |
| `slug` | string | yes | Study folder name, e.g. savings-onboarding-v1 |
| `participant` | string | yes | Participant id, e.g. P1 |
| `model` | string | yes | Model that wrote these, e.g. claude-opus-5-5 |
| `observations` | array | yes |  |
| `replace` | boolean |  | Replace all saved observations for this session instead of merging by id |

## insights_submit

Submit insights (pain points with severity, opportunities with a "How might we…" prompt) from the reviewed board, each compared with the product context (confirms / contradicts / extends / new). Requires the board to be marked done. run 2 is the independent second run: its overlap with run 1 marks insights stable. Resubmitting fixed insights merges by id, so earlier accepted ones and their review decisions are kept.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `folder` | string |  | Research folder path; defaults to ./research found from the working directory |
| `slug` | string | yes | Study folder name, e.g. savings-onboarding-v1 |
| `run` | number: 1, 2 |  |  |
| `model` | string | yes |  |
| `insights` | array | yes |  |
| `open_questions` | array |  |  |
| `replace` | boolean |  | Replace all saved insights for this run instead of merging by id (only for a deliberate full re-run) |

## compare_studies

Compare task success between an earlier and a later version of a study (re-test). Only tasks worded identically are compared. Returns the difference with a 90% interval and a plain verdict; report it as given, never compute or round differently.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `folder` | string |  | Research folder path; defaults to ./research found from the working directory |
| `before` | string | yes | Study folder name, e.g. savings-onboarding-v1 |
| `after` | object | yes |  |

## study_export

Package a study for import into the ProofLoop platform (R1) with every id unchanged: a .tar.gz with a manifest of files and SHA-256 hashes, saved in .proofloop/exports/ (not in git). Media, frames and raw transcripts are left out unless include_media is true; session notes, device details, source documents and participant names are always left out. Ask the user before including media.

| Parameter | Type | Required | Notes |
|---|---|---|---|
| `folder` | string |  | Research folder path; defaults to ./research found from the working directory |
| `slug` | string | yes | Study folder name, e.g. savings-onboarding-v1 |
| `include_media` | boolean |  |  |
